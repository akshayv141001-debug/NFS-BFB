Result

How it works

  1. Read a snip. The reader finds the Format Name, the Duration and each row's Center Time and Break Duration. It runs entirely in your browser.
  2. Check it. Compare the table with the picture next to it and fix any digit the reader got wrong. Cells that cannot be understood turn red.
  3. Save it. The Format Name becomes the Network Format. Saved formats are remembered in this browser.
  4. Use it. The output line lists break lengths from longest to shortest, with center times in ascending order inside each length.

Network Format: 180-8; 120s duration @ 0:45; 60s duration @ 0:15, 0:31, 01:15

Good to know

  • The first snip downloads the reader (about 11 MB) once; after that it works offline.
  • Clean, full-size screenshots read best. Zoom the table to fill the screenshot if rows come out wrong.
  • Centers like 0:15 mean 00:15:00 into the program. Hour 0 is written 0:MM and later hours 01:MM.
  • Saved formats are stored only in your browser. Use Export formats to back them up.
